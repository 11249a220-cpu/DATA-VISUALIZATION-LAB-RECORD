EXPERIMENT 8: DATA VISUALIZATIONS IN TABLEAU — CHARTS, GRAPHS, AND DATA MAPPING

AIM: To create different charts, graphs, and maps in Tableau to visualize data and identify patterns, trends, and relationships.

DESCRIPTION: Tableau is a data visualization tool that converts raw data into meaningful graphical representations. It provides various charts and graphs, such as bar charts, line charts, pie charts, scatter plots, and histograms. Tableau also supports geographical data mapping to display information on maps using locations such as countries, states, and cities. These visualizations help users understand complex data and make informed decisions.

APPLICATIONS:

To compare sales and profits across different categories.
To analyze trends over time using line charts.
To represent proportions using pie charts.
To identify relationships between numerical variables using scatter plots.
To visualize geographical information using maps.
To create interactive dashboards and reports.
To support business analysis and decision-making.
ALGORITHM:

Start Tableau Desktop or Tableau Public.
Connect to a suitable dataset.
Open a new worksheet.
Select the fields required for visualization.
Drag the relevant dimensions and measures to Rows, Columns, and the Marks card.
Select a suitable chart type using Show Me or the Marks card.
Customize the chart by adding titles, colors, labels, and axis names.
For data mapping, select a geographical field such as State or City.
Review the visualization and interpret the results.
Stop the process.
PROGRAM / PROCEDURE:

Tableau is a graphical data visualization tool. This experiment is performed through its interface rather than by writing a traditional programming script.

A. Creating a Bar Chart:

Connect Tableau to a dataset containing Category and Sales.
Open a new worksheet.
Drag Category to Columns.
Drag Sales to Rows.
Select Bar Chart from Show Me if necessary.
Observe the sales comparison across categories.
B. Creating a Line Chart:

Open a new worksheet.
Drag Date or Month to Columns.
Drag Sales to Rows.
Select Line from the Marks card.
Observe the changes in sales over time.
C. Creating a Pie Chart:

Open a new worksheet.
Drag Category to Color on the Marks card.
Drag Sales to Angle.
Select Pie from the Marks card.
Add labels if required to show category values.
D. Creating a Scatter Plot:

Open a new worksheet.
Drag Sales to Columns.
Drag Profit to Rows.
Add a suitable dimension, such as Category, to Color.
Observe the relationship between sales and profit.
E. Creating a Map:

Use a dataset containing geographical information such as State or City.
Double-click the geographical field to generate a map when Tableau recognizes it.
Drag Sales to Color or Size on the Marks card.
Customize the map to display the required information.
Observe differences across geographical locations.
PROGRAM EXPLANATION:

Dimensions: Categorical fields such as Category, State, and City used to group data.
Measures: Numerical fields such as Sales and Profit used for calculations.
Rows and Columns: Define the structure of a visualization.
Marks Card: Controls the appearance of marks, including color, size, labels, and chart type.
Show Me: Helps select suitable visualization types based on the available fields.
Bar Chart: Compares values across categories.
Line Chart: Displays changes and trends over time.
Pie Chart: Represents proportions of a whole.
Scatter Plot: Shows the relationship between two numerical variables.
Map: Displays data according to geographical locations.
Color and Labels: Improve the readability and interpretation of the visualization.
SAMPLE OUTPUT: Different visualizations are created in Tableau using the selected dataset:

A bar chart compares values across categories.
A line chart displays trends over time.
A pie chart represents proportions of different categories.
A scatter plot displays the relationship between two numerical measures.
A map shows geographical variations in the selected measure.
RESULT: Thus, different charts, graphs, and geographical maps were successfully created in Tableau to visualize and analyze data effectively.
