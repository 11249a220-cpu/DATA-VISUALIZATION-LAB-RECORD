EXPERIMENT 9: CREATING BASIC DASHBOARDS IN TABLEAU

AIM: To create a basic interactive dashboard in Tableau by combining multiple visualizations into a single view for effective data analysis.

DESCRIPTION: A dashboard in Tableau is a collection of multiple worksheets and visualizations displayed together on a single screen. It helps users monitor important information, compare different data values, and understand data easily. Tableau allows users to combine charts, graphs, maps, and filters in a dashboard. Dashboards can also be made interactive by adding filters and actions that help users explore data according to their requirements.

APPLICATIONS:

To monitor business performance.
To compare sales and profit across different categories.
To display important information in one place.
To analyze trends and patterns using multiple charts.
To create interactive reports for decision-making.
To present data clearly to users and management.
ALGORITHM:

Start Tableau Desktop or Tableau Public.
Connect to the required dataset.
Create a worksheet containing a bar chart.
Create another worksheet containing a line chart.
Create additional worksheets if required.
Click the New Dashboard option.
Drag the required worksheets into the dashboard.
Arrange and resize the visualizations.
Add a suitable title to the dashboard.
Add filters or interactive actions if required.
Save the dashboard.
Stop the process.
PROGRAM / PROCEDURE:

Tableau is a graphical data visualization tool, so this experiment is performed using its interface rather than a traditional programming script.

Steps to create a dashboard:

Open Tableau Desktop or Tableau Public.
Connect to a dataset containing fields such as Category, Sales, Profit, and Date.
Create Sheet 1 and build a bar chart using Category and Sales.
Create Sheet 2 and build a line chart using Date and Sales.
Create Sheet 3 and build a chart using Category and Profit.
Click the New Dashboard icon at the bottom of the Tableau workspace.
Drag Sheet 1, Sheet 2, and Sheet 3 from the Sheets panel onto the dashboard.
Arrange the charts so they are clearly visible.
Select Dashboard → Show Title, if the title is not already visible, and give the dashboard a suitable name.
Add a filter by selecting a chart's drop-down menu and choosing Add Filter or Show Filter, depending on the available option.
Test the filter and check whether the dashboard updates as expected.
Save the workbook.
PROGRAM EXPLANATION:

Data Source: Provides the data used to create the visualizations.
Worksheet: Contains an individual chart or graph.
Bar Chart: Compares sales values across categories.
Line Chart: Displays changes in sales over time.
New Dashboard: Creates a workspace for combining multiple worksheets.
Drag and Drop: Adds worksheets to the dashboard.
Layout: Arranges and resizes the visualizations.
Dashboard Title: Describes the purpose of the dashboard.
Filter: Allows users to display data that matches selected conditions.
Save Workbook: Stores the dashboard and its associated worksheets.
SAMPLE OUTPUT: A dashboard titled "Sales Analysis Dashboard" is displayed with a bar chart showing sales by category, a line chart showing sales over time, and a chart showing profit by category. A filter can be used to explore the displayed information.

RESULT: Thus, a basic dashboard was successfully created in Tableau by combining multiple worksheets and adding suitable titles, layouts, and filters for effective data visualization.
