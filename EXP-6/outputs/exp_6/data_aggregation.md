EXPERIMENT 6: DATA AGGREGATION AND STATISTICAL FUNCTIONS IN TABLEAU

AIM: To perform data aggregation and statistical calculations in Tableau to summarize, analyze, and interpret data effectively.

DESCRIPTION: Data aggregation is the process of combining multiple data values into a summarized result. Tableau provides aggregation functions such as SUM, AVG, MIN, MAX, and COUNT to summarize data. Statistical functions help analyze datasets and understand their characteristics. These functions are useful for calculating total sales, average profit, maximum values, minimum values, and the number of records. Tableau allows users to apply these functions by dragging fields into a worksheet and selecting the required aggregation.

APPLICATIONS:

To calculate total sales and total profit.
To find the average value of a dataset.
To identify minimum and maximum values.
To count records in a dataset.
To compare business performance across categories.
To support data analysis and decision-making.
ALGORITHM:

Start Tableau Desktop or Tableau Public.
Connect Tableau to the required dataset.
Open a new worksheet.
Identify the numerical fields to analyze.
Drag a numerical field, such as Sales, into the worksheet.
Select the required aggregation function, such as SUM or AVG.
Repeat the process for other statistical functions.
Compare and interpret the summarized results.
Stop the process.
PROGRAM / PROCEDURE:

Tableau is a visual analytics tool, so this experiment is performed using its worksheet interface rather than a traditional programming language.

Steps to perform data aggregation:

Open Tableau and connect to a dataset containing numerical fields such as Sales and Profit.
Open a new worksheet.
Drag the Category field to Rows.
Drag the Sales field to Columns.
Ensure that Sales is aggregated as SUM(Sales).
To calculate average sales, click the Sales pill and select Measure → Average.
To calculate minimum sales, select Measure → Minimum.
To calculate maximum sales, select Measure → Maximum.
To count records, use the Number of Records field if available, or create a suitable count calculation using an existing field.
Observe the results displayed in the worksheet.
STATISTICAL FUNCTIONS USED:

SUM: Calculates the total of all values.
AVG: Calculates the average of the values.
MIN: Returns the smallest value.
MAX: Returns the largest value.
COUNT: Counts the number of non-null values in a field.
COUNTD: Counts the number of distinct values in a field.
PROGRAM EXPLANATION:

Connect to Data: Loads the dataset into Tableau.
Rows and Columns: Arrange fields to create a table or visualization.
SUM: Adds all values in a numerical field.
AVG: Calculates the arithmetic mean of the values.
MIN: Identifies the smallest value.
MAX: Identifies the largest value.
COUNT: Counts non-null field values.
COUNTD: Counts unique field values.
Worksheet: Displays the aggregated results for analysis.
SAMPLE OUTPUT: A worksheet displays sales summarized by category. Depending on the selected aggregation function, Tableau shows total sales, average sales, minimum sales, maximum sales, or the count of values. The results help compare categories and understand the dataset.

RESULT: Thus, data aggregation and statistical functions were successfully performed in Tableau to summarize numerical data and analyze business information.
