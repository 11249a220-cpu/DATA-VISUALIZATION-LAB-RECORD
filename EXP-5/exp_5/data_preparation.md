EXPERIMENT 5: CONNECTING TO DATA AND PREPARING DATA FOR VISUALIZATION IN TABLEAU

AIM: To connect a dataset to Tableau and prepare the data by checking, organizing, and cleaning it for effective visualization.

DESCRIPTION: Tableau is a data visualization tool that helps users connect to different data sources and transform data into meaningful visualizations. Before creating charts, the data must be prepared properly. This includes checking column names, verifying data types, handling missing values, removing unnecessary fields, and ensuring that the data is organized correctly. Tableau allows users to connect to files such as Excel workbooks, CSV files, and databases.

APPLICATIONS:

To connect Excel and CSV files to Tableau.
To organize and prepare datasets for visualization.
To identify missing or incorrect values.
To change data types according to requirements.
To prepare clean data for reports and dashboards.
To support business analysis and decision-making.
ALGORITHM:

Start Tableau Desktop or Tableau Public.
Open Tableau and select the required data source.
Choose a file, such as an Excel or CSV file.
Browse and select the dataset.
Open the Data Source page.
Check the column names and data types.
Inspect the dataset for missing or incorrect values.
Rename fields or remove unnecessary columns if required.
Verify that the data is organized correctly.
Open a worksheet and use the prepared data to create visualizations.
Stop the process.
PROGRAM / PROCEDURE:

Tableau is a graphical data visualization tool, so this experiment is performed through its user interface rather than by writing a Python or R program.

Steps to connect and prepare data:

Open Tableau Desktop or Tableau Public.
Under Connect, select Microsoft Excel or Text File, depending on your dataset.
Browse your computer and select the required file.
Wait for Tableau to load the dataset.
On the Data Source page, check the data preview.
Verify the field names and data types, such as String, Number, Date, and Date & Time.
Double-click a field name to rename it if necessary.
Remove unnecessary fields when required.
Check for missing values and incorrect entries.
Open Sheet 1 to begin creating charts using the prepared data.
PROGRAM EXPLANATION:

Connect: Establishes a connection between Tableau and the selected dataset.
Select Data Source: Chooses the file or database containing the data.
Data Preview: Displays the rows and columns of the dataset.
Field Names: Identify the variables available for analysis.
Data Types: Specify whether a field contains text, numbers, dates, or other supported values.
Rename Fields: Makes column names easier to understand.
Remove Unnecessary Fields: Keeps the dataset focused on relevant information.
Check Data Quality: Helps identify missing values, incorrect entries, and inconsistent data.
Open Worksheet: Allows the prepared data to be used for creating visualizations.
SAMPLE OUTPUT: The selected dataset is successfully connected to Tableau. The Data Source page displays the dataset's rows, columns, field names, and data types. After checking and preparing the data, the dataset is ready for visualization in a worksheet.

RESULT: Thus, a dataset was successfully connected to Tableau and prepared for visualization by checking its structure, field names, and data types.
