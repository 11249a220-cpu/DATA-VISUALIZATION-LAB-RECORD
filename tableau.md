 Installation of Tableau
Aim
To download and install Tableau Desktop or Tableau Public and understand its basic interface for data visualization.

Requirements
Computer or laptop running Windows
Internet connection
Tableau installation file
Sufficient disk space for installation
Algorithm
Start the computer and open a web browser.
Visit the official Tableau website.
Select Tableau Public or Tableau Desktop according to the requirement.
Download the appropriate installer.
Open the downloaded installation file.
Follow the on-screen instructions to complete the installation.
Launch Tableau after installation.
Explore the basic interface and available data visualization options.
Stop.
Description
Tableau is a data visualization and business intelligence tool used to analyze data and create interactive charts, graphs, dashboards, and reports.

Tableau Public is a free platform that allows users to create and publish visualizations publicly. Tableau Desktop provides additional features for data analysis and dashboard development, with licensing requirements depending on the edition.

During installation, the setup file is downloaded from the official website and executed by following the installation instructions. After installation, Tableau can be opened to connect to data sources and create visualizations.

Procedure
Open the official Tableau website: https://www.tableau.com/
For the free public version, visit https://public.tableau.com/
Download the required installer.
Run the installer and accept the required installation options.
Wait until the installation is completed.
Open Tableau from the Start menu.
Verify that the application launches successfully.
Result
Thus, Tableau was downloaded and installed successfully, and its basic interface was explored.
